TetoTV experimental Aniyomi compatibility runtime

This application includes adapted runtime source API implementations from
Aniyomi v0.18.1.2, commit 39e9a749590b89b432f04b83725aaa12591371b2,
under the Apache License 2.0. Aniyomi, Tachiyomi and Mihon contributors retain
their rights. Full terms are in ANIYOMI_LICENSE.txt.
https://github.com/aniyomiorg/aniyomi/tree/39e9a749590b89b432f04b83725aaa12591371b2

TetoTV modifications replace privileged application/context/network helpers
with a limited broker interface, retain the historical manga Source ABI,
adapt the API for an Android-only library and OkHttp 5.4.0, omit Compose
marker annotations, supply bounded invocation-local preferences and QuickJS,
reject unsupported durable preferences and player arguments, and add a
constrained JSON dispatcher. These changes do not create a full
Aniyomi application or imply compatibility with every third-party extension.
No third-party content provider, extension APK or repository is bundled.
