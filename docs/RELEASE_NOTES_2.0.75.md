# TetoTV 2.0.75 Beta

> [!WARNING]
> No independent native-license review: This Beta has not received independent native-library licensing review. Automated checks verify the APK, native-source bundle, notices, pinned inputs, and checksums, but do not establish legal compliance or reproducible builds.

## What's new

- Added Spanish, Portuguese, French, Hindi, and German menus. Setup asks for a language; show titles still follow the separate Title Language setting.
- Added an early Manga reader with Seanime repositories, offline reading, and an option to turn Manga off in Settings.
- Added Kitsu account linking and tracking alongside the existing tracking services.
- Web streams now open under All when no torrent results are available. Dub and Sub tabs filter torrents without hiding Web-only results.
- Improved playback defaults, crash diagnostics, and TV navigation. Media3 with SurfaceView is the default for new settings; MPV remains selectable.

## Known issues

- Aniyomi extensions remain experimental and available only in Developer Mode. Some extensions may install without returning streams; compatibility work is paused.
- The Manga reader is an early build. Its regular repository support is Seanime only; Aniyomi sources remain experimental in Developer Mode.

## Install

Download **TetoTV-v2.0.75-universal.apk** for supported Android phones, tablets, Android TV, Google TV, and Fire TV devices.

**TetoTV-v2.0.75-native-playback-sources.zip** contains developer and license material, not an app installer. **SHA256SUMS** lists integrity hashes.
