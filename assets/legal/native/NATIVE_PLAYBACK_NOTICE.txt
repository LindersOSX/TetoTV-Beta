TetoTV native playback library notice
======================================

This Android application contains native shared libraries supplied by the
media_kit/libmpv playback stack:

* media_kit_libs_android_video 1.3.8 obtains the `default` ARM JARs from
  media-kit/libmpv-android-video-build release v1.1.7.  The JARs contain
  libmpv and libraries linked into that native build.  mpv, FFmpeg, libass,
  and their dependencies remain governed by their own licenses.

Android build repository's default-flavor MIT notice are shipped next to this
notice.  Including all four GNU license versions is deliberately conservative:
the applicable license for each file is determined by that component's
copyright notices and the exact native build configuration, not merely by
the presence of a license text.

Exact binary hashes, source revisions, rebuild instructions, known upstream
provenance limits, and APK relinking instructions are recorded in
docs/NATIVE_PLAYBACK_REDISTRIBUTION.md and
tool/release/native_playback_manifest.json.  A release distributor must make
the source/rebuild bundle generated by
tool/release/verify_native_redistribution.ps1 available from the same release
location as the corresponding APK.  This in-APK notice is not itself a
source-code offer and is not a claim that every license obligation has been
