# TetoTV 2.0.34 Beta

This beta refines the Home header and makes the profile switcher consistent across the TV interface.

## What's changed

- The editable Home search bar is about 20% shorter on TV, uses a clean rounded-rectangle shape instead of a pill, and now displays the concise placeholder “Search.”
- Direct searching from Home still supports both the Teto keyboard and the device keyboard, including predictable Left, Right, and Down D-pad exits.
- Home, Search, My List, Discover, Airing Calendar, Downloads, Watch Party, Settings, and media-management pages now use the same My List profile-switcher design on TV.
- The shared TV profile switcher consistently uses a 190×46 control with a 36px rounded-square avatar, username, and dropdown indicator.
- Phone Home keeps its compact avatar-only profile control so the header remains usable on narrow screens.
- Local-only profiles now relocate Settings consistently and no longer leave duplicate or hidden navigation targets.

## Beta notes

- This is a Beta-channel build with Android build code `410011`.
- Android does not permit an in-place install over an APK with a higher build code; future Public counterparts must use build code `410011` or newer for data-preserving switching.
- This build includes the direct Home search and season-identity improvements introduced in 2.0.33.
